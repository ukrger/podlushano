# winlocker by softicdnb

Windows 10/11 x64. Скачайте `VisualDemo-Windows-x64.zip`, распакуйте и запустите `Winlocker by softicdnb/winlocker by softicdnb.exe`.

Билдер позволяет менять заголовок и текст синего экрана, пароль и длительность сцен; справа расположен живой предпросмотр. «Предпросмотр» запускает сцены, «Собрать EXE» создаёт самостоятельный файл. Пароль по умолчанию: `1234`.

Глаз и надпись «ВАС ЗАМЕТИЛИ» перенесены из видео. На чёрном экране печатаются Booting Windows / Boot error. На красном фоне постепенно проявляется фигура с косой, тоже взятая из кадров. Синий экран воспроизводит расположение рамок, белой полосы заголовка, поля кода и красного сообщения из ролика. Заголовок по умолчанию — «Ваши файлы зашифрованы!». Подписей про демонстрацию в сценах нет.

Встроена предоставленная пользователем песня huvudskada — rotting. Новый присланный звук 0000135.mp3 преобразован в WAV и встроен в EXE: он играет сразу и каждые 2 секунды, пока виден глаз, при переходе на синий экран и при нажатии Esc. Музыка продолжает играть одновременно с сигналом. Esc не закрывает окно, на синем экране также показывает красное сообщение.

Выход — правильный пароль, кнопка «[ Выход ]» или Alt+F4. Win, Alt+Tab и Ctrl+Shift+Esc работают обычным образом. Надписи о шифровании — оформление сцены: программа не шифрует и не изменяет пользовательские файлы, не блокирует Windows, не меняет реестр и автозапуск и не использует сеть.

В архив включены полный исходный код, MP3, WAV и PNG-ресурсы для пересборки. Проверены сборка Windows x64, тесты конфигурации, вложенные аудио и графика и целостность ZIP. Запуск интерфейса и звука на настоящей Windows в этой Linux-среде не проверялся.
