# winlocker by softicdnb

Windows 10/11 x64. Скачайте `VisualDemo-Windows-x64.zip`, распакуйте и запустите `Winlocker by softicdnb/winlocker by softicdnb.exe`. Для новой версии показа соберите EXE заново новым билдером.

Билдер редактирует заголовок и текст синего экрана, пароль и длительность вступительных сцен. «Предпросмотр» запускает последовательность, «Собрать EXE» создаёт самостоятельный файл. Пароль по умолчанию: `1234`.

Глаз и надпись «ВАС ЗАМЕТИЛИ», строки Booting Windows / Boot error, фигура с косой на красном фоне и синий экран DOS. Теперь **по всей площади синего экрана** движется сетка мелких повторяющихся символов, вертикальные цветные полосы, блоки и горизонтальные сдвиги изображения, в стиле предоставленного фото неисправной видеокарты. Рисунок смещается небольшими шагами каждые 300 мс. Поле пароля остаётся чистым. В билдере этот эффект виден в анимированной миниатюре.

**Фоновая музыка удалена, писк сохранён.** WAV из присланного 0000135.mp3 встроен прямо в EXE. Писк звучит сразу и каждые 2 секунды при надписи, при переходе на синий экран и по Esc, Alt+F4 или F11. При неверном коде тоже звучит сигнал; при закрытии он останавливается. Встроенных MP3 и кода MCI в новой сборке нет, временные аудиофайлы не создаются.

Esc, Alt+F4 и F11 пищат и на синем экране показывают красное сообщение. Выход — пароль либо **Ctrl+Shift+Q** из любой сцены. Кнопки выхода нет. Win, Alt+Tab и Ctrl+Shift+Esc работают обычно; Alt+F4 в самом билдере также работает как обычно.

Надписи о шифровании и артефакты — оформление собственного окна приложения. Программа не шифрует пользовательские файлы, не блокирует Windows и не меняет настройки, видеорежим или драйвер видеокарты.

В архиве исходники, WAV и PNG. Сборка Windows x64 и тесты конфигурации/экспорта прошли. Для 2000 вариантов артефактов проверено покрытие окна и отсутствие помех на поле пароля. Полноэкранный эффект просмотрен на контрольном кадре. Проверены ресурсы, отсутствие музыки и целостность ZIP. Нативное окно и звук на Windows в этой Linux-среде не запускались.
