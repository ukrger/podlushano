# Visual Demo Studio

Визуальная демонстрация для Windows 10/11 x64 и билдер EXE.

Скачайте `VisualDemo-Windows-x64.zip`, распакуйте и запустите `VisualDemo/VisualBuilder.exe`.

В билдере можно изменить заголовок и текст синего экрана, пароль и длительность вступительных сцен. Справа отображается живой предпросмотр. «Предпросмотр» запускает всю последовательность; «Собрать EXE» создаёт самостоятельный файл показа. Пароль по умолчанию: `1234`.

Сцены: глаз с надписью «ВАС ЗАМЕТИЛИ» → строки ошибок → красная ASCII-сцена → синий экран с паролем. Предоставленная пользователем MP3-дорожка встроена, начинает играть с запуска показа и повторяется до закрытия. Писк звучит при надписи, при переходе на синий экран и по Esc. Esc не закрывает окно. Выход: пароль, кнопка или Alt+F4. Win и Ctrl+Shift+Esc сохраняют обычное действие.

Полный исходный код и MP3 для пересборки находятся в папке `source` внутри архива. Звук воспроизводится через Windows MCI; временная копия MP3 удаляется при обычном закрытии. При принудительном завершении процесса временная папка может остаться в TEMP.

Сборка Windows x64 и автоматические тесты настроек прошли. Точная MP3-дорожка проверена внутри EXE, исходный MP3 полностью декодирован FFmpeg. Интерфейс и звук на настоящей Windows в этой Linux-среде не проверялись.
