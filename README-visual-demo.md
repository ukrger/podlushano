# winlocker by softicdnb

Windows 10/11 x64. Скачайте `VisualDemo-Windows-x64.zip`, распакуйте и запустите `Winlocker by softicdnb/winlocker by softicdnb.exe`.

Билдер позволяет менять заголовок и текст синего экрана, пароль и длительность сцен; справа расположен живой предпросмотр. «Предпросмотр» запускает сцены, «Собрать EXE» создаёт самостоятельный файл. Пароль по умолчанию: `1234`.

Глаз и надпись «ВАС ЗАМЕТИЛИ» перенесены из видео. На чёрном экране печатаются Booting Windows / Boot error. На красном фоне постепенно проявляется фигура с косой из кадров ролика. Синий экран повторяет расположение рамок, белой полосы заголовка, поля кода и красного сообщения. Заголовок по умолчанию — «Ваши файлы зашифрованы!». Подписей про демонстрацию в сценах нет.

Встроена предоставленная песня huvudskada — rotting. Присланный звук 0000135.mp3 преобразован в WAV и встроен: он играет сразу и каждые 2 секунды, пока виден глаз, при переходе на синий экран и по Esc. Музыка играет одновременно с сигналом.

Кнопка выхода удалена. Alt+F4 игнорируется только в окне показа. Esc пищит и на синем экране показывает красное сообщение. Выход: правильный пароль либо **Ctrl+Shift+Q** в любой сцене, без пароля. Эта аварийная комбинация также указана в билдере. Win, Alt+Tab и Ctrl+Shift+Esc сохраняют обычное действие. В самом билдере Alt+F4 работает как обычно.

Надписи о шифровании — оформление сцены: приложение не шифрует и не изменяет пользовательские файлы, не блокирует Windows, не меняет реестр и автозапуск и не использует сеть.

В архиве полный исходный код, MP3, WAV и PNG-ресурсы. Проверены сборка Windows x64, вложенные ресурсы и целостность ZIP. Запуск интерфейса и звука на настоящей Windows в этой Linux-среде не проверялся.
